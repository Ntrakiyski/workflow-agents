# Pi document workload

This package is an application workload, not reusable Runner or Provider source. The current authorized release has only instructions/attachments, a persistent request list and request results. Clarification, feedback, revision flows, approval, project administration and skill-management UI are deferred.

Read root `AGENTS.md`, the user's minimal-release handoff and this package's README. For development or operations, read `.agents/skills/pi-document-development/SKILL.md`.

- Own only `workloads/pi-document-agent/**`. Consume versioned infrastructure APIs through the application/controller. Do not query infrastructure databases or import their internals.
- Keep `runtime-lock.json` and npm lock pinned. Archive uploads are tool bundles, never VM clones. Changing the runtime or bootstrap requires a new recorded checksum and reviewed immutable workload profile version.
- Keys enter through Provider `secret_environment` references at dispatch. Never put literal keys in profiles, images, archives, request JSON, source, logs, manifests or session checkpoints.
- Keep inbound disabled and outbound restricted to the configured existing LiteLLM HTTPS host/port. Empty outbound allowlists mean unrestricted access and are forbidden here. Report vendor network limitations truthfully.
- Pi has no built-in tools. The only document tool uses direct OfficeCLI argv against the assigned working copy. Original inputs remain immutable. No shell, arbitrary file selector, URL tool or package installation is exposed to the model.
- The durable request fence prevents replay after uncertain side effects. Preserve failed or interrupted request directories for operator reconciliation; do not delete the fence to retry automatically.
- Inspect actual bytes outside Pi before delivery. Separate OOXML structure, content accuracy and rendered layout. HTML previews do not prove pagination, translation accuracy or layout.
- Export results and required session files through scoped transfer into application-owned storage before stopping the sandbox. This package never destroys or stops its own environment; the controller owns safe export and stop sequencing.
- Use only synthetic fixtures included/generated by tests unless specific source assets are approved and available. Do not claim access to missing prototype helpers or templates.

Run `npm ci --ignore-scripts`, `npm test`, `python3 build_runtime.py`, then `python3 tests/runtime-smoke.py --runtime <extracted-runtime>`. Record real binaries, mocked checks, real model/runtime checks and blocked checks separately. A local binary pass is not Cloud or full application acceptance.
